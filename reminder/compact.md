# 摘要 / 压缩 —— 区间装配、金字塔合并、剪枝为什么没做

结论先行（大方向，AGENTS.md 留了铁律）：**压缩只往 `summaries` 插行**；摘要盖的是**一段区间**
（`begin/end_message_id`）；装配按区间跳；**只有 Compact，没有"丢"**；自动触发还没落地。

## 一、区间是怎么定下来的（2026-09-29 改）

早先"不许加起止字段"的理由是"可推导"，但推导代价是 O(路径长 × 摘要数)（要"数过去"、还要靠
"父的孩子一个不缺"兜底）✗；记一次区间换来装配与**删除级联**都是 O(1) ✓。

- 区间被"撞坏"两种情形都有出路：消息**被删** ⇒ 级联把该摘要连同父链作废（`store.DeletionPlan` 同一份计算）；
  消息**被改写** ⇒ 只标 `dirty`、**照用**（`id` 不变 ⇒ 区间仍成立）。两端可空（老数据）⇒ 装配退回逐条走原文（不会静默错）。
- **MASK**：有摘要覆盖的那段，装配时**不发明文**、只发摘要正文 —— 存放处不动，被"遮掉"的只是**这一次请求**。

## 二、装配时的行走（`state.BuildOutgoing`）

按 `id` 顺序往前走 —— 这条有 `summary_id`、且它的**区间左端就是这条** ⇒
升到最粗的左端对齐祖先、跳到区间右端之后；否则发原文。"跳过"是查区间，**不再"数过去"**。
**能取粗的不取精，但宁可用细的也不许漏内容**。

升层只看一条：**祖先与自己的左端同起点**（左端不同 ⇒ 父盖的前半截已经发过了，那是同一批孩子里的老二）。
指针悬空 / 区间缺失 / 区间不从这条起 ⇒ 这一条**照原文发**、往前一步（宁可细，不许漏）。

具体走一遍（用户的例子）：`A B C D E F G`，压缩出 `BD`(B,C,D)、`EF`(E,F)，再压出 `BF`(盖 `BD`+`EF`，
区间 B..F)。走到 B ⇒ `B.summary_id = BD` ⇒ BD 的父是 BF、**左端同起点** ⇒ 用 BF、一次跳到 F ⇒ 下一个是 G
⇒ 队列 = `A, BF, G` ✓。孩子必然在父区间里、且**左端对齐**（压缩只吃连续的段），所以"父的左端 = 这条的左端"就敢用父 ✓。

## 三、粒度：用户态按块，算法层是 Message（2026-10-01 定）

块在 `assistant → user` 交界处切（`U1 A1 | U2 U3 A3 | U4 A4 A5`）。
① **手动入口只收整块对齐**的区间，`{"blocks": N}` 也只数块；② **最后那个开着的块永不压**；
③ 章 = 凑够 N 个块（只数块，不按 token）；④ 块是**推导**的、不入库（需要指一个块时用两端消息 id）。
⇒ 细粒度能力留在算法层：摘要区间两端就是 message id，单条 Message 的摘要**合法**（存 / 装配 / 显示都支持）——
"按块"是**入口**约束，**不是数据层**约束。

- 摘要里**不存状态**：状态是**端点**属性不是段属性 —— 存进去就是第二个真相来源，改一条旧消息它就过期。
  压缩模板写死「不要把世界状态写进梗概」（`DefaultTemplate`）；上游万一写了 `<state>`，落库前被 `statelang.Scan().Cleaned` **剔掉**。
- 真需要快照时它是独立系统（`state_snapshots`：从第一条推起、能接着上一个快照推进；覆盖消息一经编辑即失效）。**现在不做** —— 现演代价足够低。

## 四、参数与次序

`compact_blocks = 10`（单位块；不给块数时用它）；预算 = 模型上下文 − 输出预留（缺省 4096）；
触发阈值用户设（**缺省 = 预算 × 0.8**，`chat/usage.go`）；停手线 / 终保护区（阈值 × 0.8 / 最近约 10k token）**还没实现** —— 自动触发没落地之前它们只是名字。

次序（✅ = 已做到，其余 ✗）：P1 预算 + 占用 ✓ · P1.5 导出/归档 ✗ · P2 摘要 ✓（手动、按块；**自动触发还 ✗**）·
P3 金字塔 ✓（合并写侧 2026-10-01：同层顶层摘要并成父）· 清原文 ✗；
装配侧按区间跳 ✓ 与删除 / Copy 时对摘要的处理 ✓ 早就在跑。

## 五、剪枝为什么没做（线性 + 区间摘要之后前提变了 ⇒ 重做设计）

早先形态是"压缩即定稿 ⇒ 只留当前路径上的孩子、其余子树删掉"，但**删消息的级联会把盖住它的摘要一起作废** ⇒
"压完就删旧消息"等于把刚落的摘要也删了 ✗。要真做，得先想清"删了之后谁来代表那段"（现在只有 Compact，没有"丢"）⇒ **先当没这回事**。
三条旧条件里仍然成立的两条：① **同一事务**；② **动手前先导出** `data/archive/*.json`；③ 报"剪掉 N 条（已导出）"，**不许静默**。
