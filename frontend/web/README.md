# frontend/web — Web 前端（当前主力）

与 TUI / TG Bot **同一条 HTTP 契约**（只调 `/api/v1`，见根目录 `AGENTS.md` 的 API 表；不碰后端内部包）。

## 跑起来

```bash
# 只起前端 dev（根目录脚本，绑 127.0.0.1:5173；**不碰后端**，后端另起、见下）：
../../start-web-ui.sh
# 或在本目录：
npm ci            # 从锁文件重装（node_modules 永不入库）
npm run dev       # vite :5173（/api 由 vite 代理到后端 —— 地址读后端自己的配置，见下）
npm test          # tsx + node 原生 test runner：纯函数与请求形状的契约测试
npm run typecheck # 严格档 + App 宽松档双检查（src 下已无 .js）
npm run build     # 产出 dist/（不入库，部署时现打）
```

后端另起：`./microchat`（8787 服务；CORS 全开，预检 204）。

**后端地址只有一份权威 = 后端自己的 `data/config/config.json`**（`server.host/port`）：vite 启动时读它，
把 `/api` **代理**给后端（`vite.config.ts` 的 `server.proxy` + `preview.proxy`；读不到 ⇒ 默认 `127.0.0.1:8787`，
目录可被 `MICROCHAT_DATA_DIR`/`MICROCHAT_CONFIG_DIR` 覆盖）。所以浏览器**永远同源**、不用填地址 —— 启动自检的
候选也是**同源优先**（`http://<当前来源>/api/v1`），"跟页面同主机的 8787"退为兜底（没有代理的静态部署）。
Docker 部署（单容器、只公开 8788）见根目录 `docker-compose.yml`：地址口径与此完全同一条。

## 依赖

`vue@3.5`（框架）+ `marked`（markdown 渲染）+ `katex`（数学）+ `vuetify@4`（**底部输入栏 + 设置界面控件**，渐进接入；主题色由 Vuetify theme 控制）；构建用 `vite` + `@vitejs/plugin-vue` + `vite-plugin-vuetify`。
运行时没有自造传输层（`fetch` 直调）。**加依赖先问**；`node_modules/`、`dist/` 永不进库。
开发依赖另有 `typescript` / `vue-tsc` / `tsx`；`src/` 下已全部 TS（App 组装根用宽松档检查）。

## 现在能干什么

- **会话**：首句才创建会话；刷新恢复上次阅读的会话。首次载入显示骨架，正文短淡入；命中缓存则立即显示。消息列按段分页，默认每页 5 段，展开摘要时才读取原文。
- **流式生成**：受理前显示「正在向后端发送请求」，受理后显示「等待 Provider 响应」，两段等待共用星芒动效。SSE 按生成步骤和两条 UTF-8 字节游标续读正文、思考；重放只补未显示的部分，断线时无需刷新页面。减少动态效果时，等待图标静止、正文不淡入。
- **服务端工具**：同一条回复多次搜索时，查询与来源各有自己的卡片，按发生位置穿插在正文里。生成中和刷新后都保持顺序；没有位置记录的旧工具仍可在「查看过程」中打开。
- **上下文工作区**：与聊天并列，提供请求预览、世界状态和历史压缩。草稿可以预览，但没有可压缩历史。
- **设置**：按「常用设置」「对话与模型」「数据与维护」分组。搜索框可直接定位到具体控件，例如「回车」「字号」「自动压缩」；按 Enter 打开首个结果。新会话默认值独立于上下文与生成设置，外观、发送和消息渲染分开。外观和输入偏好保存在服务器；缩放需点「保存缩放」。
- **管理**：左栏底部只保留「设置」。在设置目录进入「渠道与模型规则」或「智能体」；会话页可打开、导出、导入或删除会话，酒馆页处理 SillyTavern 预设与聊天记录。应用没有账号或登录。
- **触屏**：窄屏侧栏可滑动开合；「外观」可以关闭滚动时收起顶栏／底栏。
- **移动端键盘不遮输入框**：visualViewport 拟合应用盒（浮层随键盘抬、命令面板限高不顶出小视口）
- **PWA（可"安装为应用"）**：`vite-plugin-pwa`（v2）。**只在 build/preview 开 SW**（dev 不开——免得开发时吃到旧缓存）。SW **只预缓存壳**（HTML/JS/CSS/图标/字体）：离线打开能进"连接门板"；`/api` 一概不碰（数据必须现取 —— 现在 `/api` 走 vite 代理、与页面同源，SW 是**够得着**它的，所以这条不是"管不着"而是**刻意不接**：不许写 runtimeCaching）。**安装的前提在来源：HTTPS 或 localhost** —— 局域网 `http://<IP>:8788` 装不了（不是安全上下文，连 SW 都不会注册）；云端形态（反代终结 TLS，如 Cloudflare）天然满足。图标 `public/pwa-192.png` / `pwa-512.png` / `pwa-maskable-512.png` / `apple-touch-icon.png`（由 `favicon.svg` 栅格化）。桌面/安卓 Chrome：地址栏装或菜单"安装应用"；iOS 16.4+：分享菜单"添加到主屏幕"。**更新由用户点**（2026-10-20 起）：检测到新版本 ⇒ 顶上弹一条**不自动消失**的更新条（`components/UpdateBar.vue`）⇒ 点「刷新」才切过去。**别再用"再刷一次就是新的"来理解它** —— 从前是 `autoUpdate`，它**静默**自己 reload 且从不告诉你"此刻看的是旧的"（2026-10-20 因此对着一个"文件是新的、界面却是旧的"白排查一轮，最后靠清站点数据才揭穿是 SW 缓存的旧壳）
- **断线提示**：启动时优先探测同源 `/api/v1`；探不通时显示连接提示。
- **命令面板**默认关闭，可在「输入与发送」开启。直接输入已有命令仍可执行，例如 `/resume`、`/compact`、`/reroll`。
- **上下文环**显示相对于输入预算的用量（模型上下文上限减去输出预留），并可打开任务面板。
- **共享层**：`utils/prefs.ts` 管界面偏好、主题与发送键；`api/client.ts` 处理 HTTP、SSE 地址和流式增量合并；接口错误按 `code`/`status` 分支。

口径、路由表与"为什么这么设计"全在根目录 `AGENTS.md`。
