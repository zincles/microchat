# frontend/web — Web 前端（当前主力）

与 TUI / TG Bot **同一条 HTTP 契约**（只调 `/api/v1`，见根目录 `AGENTS.md` 的 API 表；不碰后端内部包）。

## 跑起来

```bash
# 只起前端 dev（根目录脚本，绑 127.0.0.1:5173；**不碰后端**，后端另起、见下）：
../../start-web-ui.sh
# 或在本目录：
npm ci            # 从锁文件重装（node_modules 永不入库）
npm run dev       # vite :5173（/api 由 vite 代理到后端 —— 地址读后端自己的配置，见下）
npm test          # node 原生 test runner：纯函数与请求形状的契约测试
npm run build     # 产出 dist/（不入库，部署时现打）
```

后端另起：`./microchat`（8787 服务；CORS 全开，预检 204）。

**后端地址只有一份权威 = 后端自己的 `data/config/config.json`**（`server.host/port`）：vite 启动时读它，
把 `/api` **代理**给后端（`vite.config.js` 的 `server.proxy` + `preview.proxy`；读不到 ⇒ 默认 `127.0.0.1:8787`，
目录可被 `MICROCHAT_DATA_DIR`/`MICROCHAT_CONFIG_DIR` 覆盖）。所以浏览器**永远同源**、不用填地址 —— 启动自检的
候选也是**同源优先**（`http://<当前来源>/api/v1`），"跟页面同主机的 8787"退为兜底（没有代理的静态部署）。
Docker 部署（单容器、只公开 8788）见根目录 `docker-compose.yml`：地址口径与此完全同一条。

## 依赖

`vue@3.5`（框架）+ `marked`（markdown 渲染：`**粗**`/`*斜*`/`__下划线__`→`<u>`/行内码/`~~删~~`/引述块）+ `katex`（数学）；构建用 `vite` + `@vitejs/plugin-vue`。
运行时没有自造传输层（`fetch` 直调）。**加依赖先问**；`node_modules/`、`dist/` 永不进库。

## 现在能干什么

- **会话**：草稿态（点＋只开一张客户端草稿，**首句才建会话**；**开机/刷新回到上次在看的那条会话**——`mc_last_session` 取不到就回草稿）· 发送/流式（202 受理 + 轮询 + 游标读）·
  重发 / 重摇 / 压缩 / 删除（带预览与确认）· 改名 / 换模型 / 换 Agent / 会话提示词 · ST（SillyTavern）JSONL 导入 · 消息列只挂最后 20 段（`加载更多历史` 往回翻页；摘要卡展开才拉原文） · 摘要卡可 `⟳` 刷新（重摇出候选、旧版不丢）/ `✎` 编辑 · **首段对话**（agent 配了 `first_message` 时，新会话自动带一条开场 assistant 消息；草稿里先合成画出来） · **对话导出/导入（JSON）**（会话设置与设置→会话 的行里都能导出 = 只有 role/content+标题；设置→会话 里导入） · **agent 卡带**（智能体编辑器里「导出卡带」= agent + 它引用到的用户段随卡走；智能体 tab 里「导入卡带…」，已有同 id 段就复用、缺的才建并打「导入」标）· 输入框上方一行后台任务数（`/tasks`） · 消息列带编号（`你 #2`），摘要段折成 `Summary #a-b` 卡（可展开未压缩原文）
- **右载荷栏**：真请求预演（草稿也能 —— 客户端铸会话 id，`POST /outgoing`；载荷 tab 可切**分块视图**——把 `body.messages` 一块块画成卡片，比读裸 JSON 直观；**整行可点开合、长块（>500 字）默认折叠**）+ 世界状态 tab + **压缩树**（文件管理器那种看体积的树：目录 = 摘要、嵌套 = 嵌套压缩）
- **设置六 tab**：聊天 / 连接 / 会话 / 智能体 / 渠道 / 提示词（与对话**同级的视图**，不是弹窗；窄屏自动收起左栏）。「提示词」= 可复用提示词段的库（system prompt segment），「智能体」里逐段追加。**入口（⚙）只有 root（管理员）看得见**：普通用户连按钮都不给，进设置还有守卫兜底
- **登录 / 初始化**：第一次打开是「初始化 root」（uid 0 是建库种子，setup 只给它设口令、**只开一次** —— 不是注册制），之后是登录（JWT 存 `mc_token`，全请求带 `Authorization: Bearer`）；登出在用户视图
- **用户视图**（与设置平级，左栏底 `👤 用户`，人人可进）：身份（名字 · 管理员 · 退出登录）+ **改口令（自己）**（改完当场重登换票）+（**admin 才有**的）**用户管理**：列表 / 加人 / 行内改名、改口令 / 删人（两步确认："会话转给 root / 连会话一起删"）+ 个人偏好 —— 主题七套（默认 `deepseek`，色值实测对齐 chat.deepseek.com）· **背景图**（URL 或上传，本地存；没设 = 纯平底）· 发送键 · 输入预演
- **滑动面板**（触屏**跟手**）：左滑出右栏、右滑出左栏，半开维持、松手吸附；先关后开
- **移动端键盘不遮输入框**：visualViewport 拟合应用盒（浮层随键盘抬、命令面板限高不顶出小视口）
- **PWA（可"安装为应用"）**：`vite-plugin-pwa`（v2）。**只在 build/preview 开 SW**（dev 不开——免得开发时吃到旧缓存）。SW **只预缓存壳**（HTML/JS/CSS/图标/字体）：离线打开能进"连接门板"；`/api` 一概不碰（数据必须现取 —— 现在 `/api` 走 vite 代理、与页面同源，SW 是**够得着**它的，所以这条不是"管不着"而是**刻意不接**：不许写 runtimeCaching）。**安装的前提在来源：HTTPS 或 localhost** —— 局域网 `http://<IP>:8788` 装不了（不是安全上下文，连 SW 都不会注册）；云端形态（反代终结 TLS，如 Cloudflare）天然满足。图标 `public/pwa-192.png` / `pwa-512.png` / `pwa-maskable-512.png` / `apple-touch-icon.png`（由 `favicon.svg` 栅格化）。桌面/安卓 Chrome：地址栏装或菜单"安装应用"；iOS 16.4+：分享菜单"添加到主屏幕"
- **连接门板**：进前端第一眼 —— 探通后端后它只用来**初始化 root / 登录**；探不通才是全屏"连接"面板（探针候选：**同源 `/api/v1` 优先**，其次跟页面同主机的 `<该主机>:8787`；裸地址自动补 `http://` 与 `/api/v1`；探通即存偏好刷新进聊天）。**地址栏只在探不通时出现**（2026-10-14）：同源部署（vite 代理/单容器）里登录界面不会让你填后端地址；中途连接又断了，地址栏会自动放回来
- **命令面板**：`/` 进（`/resume` `/compact` `/cut` `/reroll` `/edit` `/editsum` …，只放已有路由的命令）
- **共享层**：`utils/prefs.js`（界面偏好 + `sharedApi()` + 发送键判定/主题应用，含 TG 守卫）· `api/client.js` 的 `mergeStreamSlice`（流式合并唯一规则）· 错误带 `code`/`status`（按 code 分支）· `format.js` 的 modelKey/modelLabel/whoText/sessionTitle（键与标签唯一出口）

口径、路由表与"为什么这么设计"全在根目录 `AGENTS.md`。
