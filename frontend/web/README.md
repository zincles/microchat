# Web 前端

Vue 3、TypeScript、Vuetify 4（MD3）、Vite。Web 通过 `/api/v1` 调用 [Go 路由表](../../core/internal/server/server.go)，不依赖其内部模块。

## 开发与验证

从仓库根运行 `./start-web-ui.sh`：它只启动前端，并在首次缺少 `node_modules` 时安装锁定依赖。也可在本目录运行：

```bash
npm ci
npm run dev -- --host 127.0.0.1
npm run typecheck
node --import tsx --test test/readingContinuity.test.ts  # 示例：只跑行为直接相关的测试
npm run build
```

`npm run typecheck` 检查严格档与 App 组装档；测试使用 `tsx` + Node test runner。`dist/` 和 `node_modules/` 不入库。新增依赖先确认。后端另起，或使用本机容器的 `8787`，不要与其同时写真实 `data/`。Vite dev/preview 从后端配置取得 `/api` 代理目标，默认 `127.0.0.1:8787`；独立验证时给两进程同一个临时配置目录。

## 聊天界面的约定

- **导航。** 左栏「对话 / 生图 / 项目」中只有对话已接入。打开时只从左栏内收起；关闭时，聊天、上下文、设置、关于和账户的左上角显示打开按钮。触屏滚动隐藏聊天控件时也保留打开入口。聊天没有通栏，模型按钮与「聊天 / 上下文（或工作流）」切换独立悬浮。模型分组按归属或渠道，搜索仅作用于浏览；「设当前为新会话默认」不改已有会话。
- **会话列表。** 未收藏星标与三点菜单仅在当前会话、鼠标悬停或键盘聚焦时出现；已收藏的金黄色实星常驻。会话选项和输入栏菜单都用 Vuetify 的锚定开合动效。
- **阅读。** 默认取 5 段，每段是一条消息或顶层摘要；摘要原文展开时再取。按会话 ID 缓存窗口、阅读锚点和未发文字，草稿文字与锚点不进浏览器持久存储。迟到的对账不能覆盖刚发送、编辑或切换后的界面。只有贴尾时随流跟随；读旧消息时显示「回到最新」，它只滚动。切回前台以服务端相位为准，活的流继续接，不用重拉存档覆盖它。
- **流式与操作。** 受理前、等待 Provider、生成中各有不同提示；正文和思考以独立字节游标续读，前端摊开新字符，不直接把整块打上屏。回复按 `run_id` 分组，有可靠位置的搜索按事件所在位置穿插，否则只在「查看过程」。复制回答不带工具回填、思考或世界状态。窄屏重摇时编辑、删除、翻版仍同排可点。
- **输入和编辑。** 输入卡与阅读列同宽；有文字用上箭头发送，已有历史的空输入用下箭头续写，无历史禁用空发。助手与发送键圆心对齐输入卡的圆角。正文与思考共用编辑窗口，切换位于标题栏全屏键左侧；窗口不投影，文本区上下以工具栏底色区分，不加渐隐或分隔线。保留两字段未保存修改和服务器中的最近编辑偏好。消息删除先预览并确认。
- **上下文。** 请求预览、世界状态、历史压缩分别按需加载；请求预览可独立关闭，分块默认折叠。压缩预演不调模型，开始压缩才执行。输入卡圆环显示输入预算与任务数；普通会话任务计数取服务端任务快照，Flow 圆心显示节点 LLM 调用数，不互套口径。
- **布局。** 文档不滚，消息列、侧栏和上下文各用实际滚动容器；仅在这些长驻区域预留滚动条槽。顶端、底端渐隐只遮消息阅读区，不遮控件，也不改变首尾留白。触屏上方控件与输入卡可随滚动收起，键盘尺寸由 `visualViewport` 适配。过渡尊重减少动态效果。
- **设置。** 首页仍按五类排列；目录、搜索结果与常用表单借鉴 Miuix，组名在外、组内共用一个大圆角底面，不给每行套卡。配色与控件保留 Vuetify MD3。窄屏的长字段上下排列，开关仍在行尾。「对话」和「外观与输入」各分节的保存范围不变；搜索仍直达控件，返回目录保留查询。
- **提示词片段库。** 与其它管理页共用列表：名称可换行，正文只显示两行预览，内置／导入、预设来源与引用者就地显示。桌面和手机使用同一布局；点条目查看或编辑，行尾「复制」独立创建副本。

## 共享层与样式

- `src/plugins/vuetify.ts` 是主题色权威；CSS token 统一映射，组件不用自订同名颜色。复用现有模式开关、菜单、形状、状态层；Vuetify 样式在 CSS layer 内，旧原生基线不得压住组件交互。提示词片段选择复用 `SegmentList.vue`。
- `src/utils/prefs.ts` 负责偏好、缓存和共享 API。服务器 `prefs.json` 是权威；`mc_prefs` 只是首帧镜像，`mc_api` 与 `mc_last_session` 是设备级记录。设置变更先改值再保存；不要用 `v-model` 叠一个可能读旧值的保存监听。松手或页面隐藏时按现有 `flushPrefs()` 写回。
- `src/api/client.ts` 统一 HTTP、错误和流式合并；`utils/markdown.ts` 转义裸 HTML、按设置渲染 Markdown，关闭某种语法要原样显示标记。只读宏不回写原文。命令菜单默认关，直接输入已有命令仍可执行。
- `src/composables/useSessionWindow.ts` 管分页与阅读锚点；`useTurnStream.ts` 管流生命周期。新组件不要另起一份消息或权限状态；Vue 模板不要直接使用不在组件作用域的全局对象。

PWA 只在 build/preview 注册 Service Worker，不缓存 `/api` 或 `/build.json`。服务器构建更新和页面壳更新分别检查；验部署时在浏览器确认已加载新壳。改 `public/favicon.svg` 后运行 `sh scripts/render-app-icons.sh`（ImageMagick）更新普通、可遮罩与 iOS 位图；保留 manifest 路径，使用内容指纹更新图标 URL。
